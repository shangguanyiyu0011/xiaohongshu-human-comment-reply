# 真人化回复写作规则

## 先判断评论意图

- **具体提问**：直接回答已知事实；不确定时说明核实入口或转人工。
- **分享经历**：接住对方说的具体细节，再自然延伸一句。
- **有内容的认可**：回应其点名的地点、菜品、路线或感受，不用空泛致谢。
- **纠正或补充**：感谢具体补充，确认能核实的部分；不要为了和气承认错误事实。
- **轻松玩笑**：可顺着语气简短回应，但不冒犯、不越界。

## 推荐结构

任选一种，不要同批机械复用：

- `具体回应 + 一句补充`
- `具体回应 + 自然追问`
- `简短确认 + 可操作建议`
- `接住情绪 + 明确边界`

## 自然度检查

- 回复脱离原评论后仍适用于任何人，说明太模板化，应重写。
- 两条回复只有称呼不同，说明重复，应重写其中一条。
- 表情只在确实增加语气时使用，通常 0–1 个；不固定放在句末。
- 避免连续使用“哈哈哈”“姐妹”“宝子”“亲”等称呼，除非账号既有语气明确如此。
- 不使用“感谢您的支持”“您的反馈我们已收到”等客服模板。
- 不做虚假稀缺、效果保证、交易承诺或诱导性私信话术。

## 例子

原评论：`雨季去会不会一直下雨？`

- 合适：`阵雨会多一些，出发前还是以当天预报和景区公告为准～`
- 不合适：`亲亲，感谢关注，建议提前查看天气哦！`

原评论：`我最喜欢你写的老街那段`

- 合适：`老街确实很耐逛，傍晚灯亮起来以后气质又不一样。`
- 不合适：`谢谢喜欢！记得收藏关注哦～`

原评论：`住哪家酒店好？`

- 默认动作：`skip`，原因写明“住宿推荐不在默认回复范围”。
